# Ideas futuras para cartas de módulos técnica

## Centro de procesamiento de datos

**Estado:** idea pendiente; no incorporar todavía como carta.

Crear una carta **Centro de procesamiento de datos** que represente infraestructura para almacenar, organizar, transmitir y procesar grandes volúmenes de información.

- **Técnica que podría otorgar:** Datos (DAT).
- **Posible relación tecnológica:** Electrónica como requisito, a evaluar.
- **Motivación:** distinguir la capacidad de gestionar y analizar datos de la mera obtención de mediciones por sensores.
- **Balance y progresión:** no es obligatorio que ninguna carta actual otorgue DAT. No forzar la asignación de esta técnica a cartas existentes solo para garantizar una fuente.
- **Pendiente:** definir receta, etapas, efectos y si finalmente otorga DAT.

Esta nota no modifica las cartas existentes.
